# Audit — full functionality, security, and performance sweep (2026-10-23)

Scope: the whole implemented surface — kernel (config, http, cache, renderer), middleware
(trust-proxy, rate-limit, request-id, request-log, tracer), database (adapter, dialect, migrator,
seeders, migrations), user module (service, repo, cache, schema, SSR, client), observer (logger,
tracing, metrics), CLI commands, the Vite plugin, and the Solid routes. Method: full source read,
data-flow review against the OWASP categories, race/leak review of every resource acquisition, and
a validation run.

## Validation

- 27/27 unit and integration tests; typecheck and `vpr check` clean.
- E2E 14/14 (Chromium + Mobile Chrome).
- `pnpm audit`: no known vulnerabilities; no hardcoded secrets outside documented dev defaults.
- Live probes on a fresh build: hardening headers on pages and API, rate-limit counters
  incrementing across requests, docs endpoints 200, client asset 200, unknown user 404, dev API
  carries `x-request-id`.

## Findings

- D1 — SQLite opened with the node:sqlite default busy timeout of 0: concurrent writers on a
  shared database file fail immediately with SQLITE_BUSY. Fixed: `DatabaseSync(path, { timeout: 5_000 })`.
  status: resolved · updated 2026-10-23
- D2 — the dev `apiHandler` lacked the request-id and request-log middlewares the serve command
  has. Fixed: both (plus the security-headers middleware) merged into the dev handler.
  status: resolved · updated 2026-10-23
- D3 — the database rate-limit store counted with an upsert plus a separate SELECT; two processes
  could read the same count. Fixed: single upsert with `returning('count')`.
  status: resolved · updated 2026-10-23
- D4 — the `http_requests` method label accepted any raw request method, so exotic methods grew
  the series set. Fixed: methods bounded to the known set, others recorded as `OTHER`.
  status: resolved · updated 2026-10-23
- D5 — the `Cacheable` service key was declared with an erased (`any`) self type. Fixed: typed to
  its own service interface.
  status: resolved · updated 2026-10-23
- P1 — `HttpStaticServer.make` ran per request, rebuilding the handler's mime map and closures.
  Fixed: built once and memoized; build failures are a defect, request failures retry.
  status: resolved · updated 2026-10-23
- S1 — no security response headers (CSP, `X-Content-Type-Options`, `X-Frame-Options`,
  `Referrer-Policy`). Fixed: a global `securityHeaders` middleware on both composition roots; the
  CSP allows inline styles only, and the e2e suite confirms hydration still works.
  status: resolved · updated 2026-10-23
- S2 — `/metrics` is unauthenticated. Accepted as designed for in-network scraping; access control
  belongs to the reverse proxy, documented in `docs/configuration.md`.
  status: wontfix · updated 2026-10-23
- S3 — dev-default credentials in source and compose (`edgy-dev-ingestion-key`, `securedb`).
  Accepted: documented development defaults, not production secrets.
  status: wontfix · updated 2026-10-23
- S4 — the rate-limit key is the post-trust-proxy client IP; `TRUST_PROXY=true` makes it
  spoofable by configuration choice. Accepted: the config's meaning, not a defect.
  status: wontfix · updated 2026-10-23
- P2 — the SQLite driver is synchronous, so queries block the event loop. Accepted for the
  reference SQLite setup; revisit when a postgres driver lands.
  status: wontfix · updated 2026-10-23
- P3 — `users.list()` is unpaginated. Accepted at scaffold scale.
  status: wontfix · updated 2026-10-23
- C1–C4 — dead exports removed: `cli.ts` `runWith`, the `RateLimit`/`RateLimitInsert` aliases,
  `dialect-helpers` `isSqlite` (and the now-internal `detectDialect`), `user_schema` `UserUpdate`.
  status: resolved · updated 2026-10-23

## Clean bills

No memory leaks (every resource closes through scopes, finalizers, or explicit disposal), no SQL
injection surface (all queries parameterized through Kysely), no XSS surface (no raw HTML sinks),
error bodies carry no internal causes, and the trust-proxy chain resolution is correct.
