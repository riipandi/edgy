## What stayed open / the trap

- The trap that bit hardest: **the route tree generator regenerates lazily and both `router.routesDirectory` and `router.generatedRouteTree` resolve against `srcDirectory`.** Values like `src/routes` silently sent the generator to `src/src/...`; because the generator only rewrites `routes.gen.ts` when its computed content differs, the stale-but-correct file masked the bug until the route file list changed. Values are now `routes` and `routes.gen.ts`; a clean checkout generates the tree during `vpr build` before check/typecheck.
- Second trap: `setResponseHeader` inside a server function does not reach the HTML response. The D7 bridge is `src/kernel/page_meta.ts` (request-scoped meta shared via `globalThis`) written by the server-function handler and copied onto the response by the Start request middleware in `src/start.ts`.
