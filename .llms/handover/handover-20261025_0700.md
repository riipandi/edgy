## What changed and why it matters

- **The remote path has no transaction slot left** (F-01). Phase 1 cleared the slot before the await;
  phase 2 then removed the slot entirely: the remote executor drives `Session` from
  `@tursodatabase/serverless` directly (`sequence('BEGIN'/'COMMIT'/'ROLLBACK')`, `session.execute`),
  so a failed `COMMIT` cannot poison anything structurally.
- **Every remote request carries a 5-second abort signal** (F-02). The `/compat` client was dropped by
  discovery, not preference: it builds its session from `url`/`authToken`/`remoteEncryptionKey` only
  and silently drops `defaultQueryTimeout` — proved against a stub before the change.
  `REMOTE_QUERY_TIMEOUT_MS = 5_000` on the `Session` is what makes it real.
- **The remote transport is verified at acquire** (F-06): one bounded `select 1`, the session closed on
  failure, so a wrong host or a revoked token fails the layer instead of the first request. Measured:
  an unresolvable host exits `1` in 0.55 s.
- **`http://` logs one boot warning** (F-04's sibling F-03): same warning channel as the ignored-token
  case, silent for every encrypted scheme.
- **The sidecar sweep matches `<basename>-*`** (F-04): the engine's `-tshm` was left at the process
  umask by the fixed suffix list. Now every file the engine writes beside the database is `0600`.
- **`streamQuery` clamps a non-positive chunk size to one row** (F-05). Reverting the clamp hangs the
  whole suite — the spec is the guard.
- **`insertId` only for an insert** (F-07), both transports, agree on the shape.
- **The audit's repros became permanent specs** in `src/database/dialect.test.ts` (the failed-commit,
  unreachable-host, and chunk-size discoveries), each failing when its behavior is reverted.

## Test-integrity lessons this session (apply to the next specs)

- **Kysely's `stream()` flattens driver chunks into single rows** — chunk boundaries are observable
  only through `db.getExecutor().stream(compiled, n)`. A spec that asserts row order over `.stream()`
  says nothing about chunking.
- **Kysely's `UpdateResult`/`DeleteResult` carry no `insertId` field**, so a typed assertion through
  `.updateTable()` is vacuous — it passes with no behavior at all. Use `sql`…`.execute(db)` and assert
  on the raw result.
- **Log strings are asserted verbatim; keep a message and its assertion in one edit** — the
  capitalization sweep touched ten tests that way. A status-line filter keyed on `line.includes('Z')`
  was matching temp-directory names; migrate status assertions use the ISO-timestamp regex instead.
