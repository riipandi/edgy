## Facts future sessions should know

- The `QueryClient` is created inside `getRouter()` only — `getContext()` has exactly one call site; a second call would hand a foreign client to whatever asked.
- `wrapQueryClient: false` keeps `RootProvider` as the single `QueryClientProvider`; the integration's default monkey-patches `router.options.Wrap` to add another.
- `head`'s `loaderData` carries an extra `undefined` union even when the loader never returns it; `userTitle` accepts `UserResult | null | undefined`.
- Usage inside `createIsomorphicFn().server()` is the import-protection guard's compiler-safe boundary — that, not `behavior.build: 'mock'`, is what silences the client-bundle warnings (the mock changes emitted code but the warning still fired).
- `devtools()` takes the same `uiPreview` gate as `tanstackStart` because Storybook builds its own entries.
- The prod-bundle devtools check greps `dist/` for devtools identifiers; tree-shaking removes the DEV-guarded import, verified.
- The SSR HTML carries the dehydrated query state under the `dehydratedData` marker (not `dehydratedState`).
- `vpr dev` serves on port 3000 (`server.port`), and killing `vpr dev` does not kill the spawned `vite.js dev` child — E2E fails with "already used" until the child is killed too.
