## What changed and why it matters

- **The standalone container renders pages again** (F-01, high). The SolidStart SSR bundle is
  emitted from Vite's built-in `ssr` environment, which the standalone branch never inlined — every
  page 500'd in the distroless container since `afaf0f3ec`. The standalone resolve inlining now
  covers `environments.ssr` too, and a build-time guard fails the build naming any bare external
  import left in `dist/` (F-02's enforcement side).
- **Redis outages no longer kill the boot** (F-03). `src/kernel/redis-boot.ts` wraps both Redis
  layer builds in a bounded retry (30 × 1 s); compose gates the app on redis `service_healthy`.
  Late Redis → serve waits and recovers; dead Redis → bounded exit with `RedisError` surfaced.
- **The runtime metrics sampler shares the `METRICS_ENABLED` gate** with the `/metrics` endpoint
  (F-04): off means no endpoint and no sampling fiber.
- **`APP_BASE_URL` rejects empty values** at the parser (F-05). Note the boundary: the OS-env
  provider treats an empty variable as unset, so the documented default applies at the env edge;
  the rejection guards non-env sources and the parse contract.
