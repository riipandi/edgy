# Marko features parked

Marko features the pages could use, each with the trigger that unlocks it. Evaluated against the Marko reference docs and the current pages (`/users`, `home`, `error`). Plans touched: none.

## 1. Out-of-order streaming (`<try>` with `<@placeholder>`)

- **status**: open
- **what**: render a page's shell first and let a slow, secondary part arrive later. Marko injects a small script to move the late fragment into place.
- **why parked**: no page has slow data. `/users` reads one paginated query, so there is nothing to defer.
- **cost to know before starting**:
  - Status and headers are fixed at the first flushed byte. A failure inside `<try>` can no longer become a `404` or `500`. Data that decides the status stays in `load`; only supplementary data goes in `<try>`.
  - Work inside `<try>` runs outside `runProgram`, so it loses the timeout, span, cache tally and error reporting unless it is routed back through them.
  - The late fragment depends on client script. Every inline script it adds must carry the response nonce.
  - A placeholder must reserve its final height, or the page shifts.
- **trigger**: a page with a slow section that is not needed to pick the status, such as a report, a feed or a remote call.

## 2. Lazy loading of interactive tags (`with { load: "…" }`)

- **status**: open
- **what**: split a tag's browser code into its own chunk, fetched on `visible`, `idle`, `media` or an event. The server still renders the full HTML.
- **why parked**: `user-list` is the only interactive tag and it is small, so a split saves nothing.
- **cost to know before starting**:
  - It needs `linkAssets`, which `@marko/vite` sets. Without it the import compiles as eager and nothing fails, so confirm with a browser test that the chunk is requested late.
  - A new chunk must be served on every target: `directoryAssets` on Node, the embedded blobs in the single executable, and Cloudflare's assets binding on the Worker.
  - The trigger is a build-time string, and only default imports work. Put it behind one facade tag per component.
- **trigger**: an interactive tag heavy enough to matter, such as an editor or a chart.

## 3. Patch protocol and shared layouts

- **status**: open
- **what**: navigation updates the live document with a stream of patches, so a layout keeps its own state across pages.
- **why parked**:
  - Marko marks it experimental; the option, the response format and the client runtime can change in any release.
  - It works only under `@marko/run`'s route rendering. Routing here belongs to h3.
  - It needs `'unsafe-eval'` in `script-src`, which the HTML policy refuses.
  - No layout holds state that should survive a navigation.
- **trigger**: all of these at once: Marko calls the protocol stable, it no longer requires `@marko/run`, it works without `'unsafe-eval'`, and a layout has state worth keeping.
