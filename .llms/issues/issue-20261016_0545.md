# Audit findings left open

An audit of security, concurrency, performance, flows and stale code. The findings that were safe or decided were fixed in the same pass; these remain. Plans touched: none.

## 1. Telemetry export can stall on a response body

- **status**: open
- **what**: the 5 s deadline in `ExportHttpClient` covers response headers only. A collector that sends headers and then stalls the body leaves the export fiber blocked, the buffer grows, and each batch boundary forks another stalled export. The body is read inside the vendored exporter.
- **fix sketch**: read the body under the same deadline in `ExportHttpClient` and hand the exporter a response rebuilt from the bytes.
- **trigger**: the first collector outage that does not refuse connections, or before enabling OTLP in production.

## 2. A drain does not wait for streamed bodies

- **status**: open
- **what**: `inFlight.leave()` runs when the handler returns the `Response`, not when its body ends, so shutdown can cut a streaming page or asset while reporting a clean drain.
- **fix sketch**: leave on stream close or cancel.
- **trigger**: the first streamed route that takes longer than a request's headers.

## 3. Wrong method answers `404`, not `405` with `Allow`

- **status**: open
- **what**: `POST /` or `DELETE /users` hit the catch-all. A correct `Allow` needs the router's own view of which methods match a path, which h3 exposes only through internals (`~rou3`).
- **trigger**: h3 exposing a public route lookup, or an owner decision to keep a method table beside the routes.

## 4. The Worker has no tests and a bare failure path

- **status**: open
- **what**: `src/worker.ts` is untested (60 uncovered statements). A failed isolate build answers with Cloudflare's bare 500, with no envelope, request id or security headers. The per-isolate app is keyed by the `env` object's identity, so a runtime that passes a fresh `env` per request would rebuild and re-migrate every time.
- **trigger**: any change to the Worker entry; verify with `pnpm preview --mode worker`.

## 5. Smaller items

- **status**: open
- `builder/compile.ts` overwrites `dist/edgy` before injection and leaves a plain Node binary there when it fails. Write to a temporary path and rename.
- `redact.ts` leaves gaps: `scheme://user:pa/ss@host` is not redacted, `user:p@ss@host` leaks `ss`, and an unquoted `password=a b` leaks `b`.
- `clientAddress`: an empty or trailing entry in `X-Forwarded-For` (`1.2.3.4,,10.0.0.2`) and a bracketed IPv6 with a port fall back to the proxy's address; a `::/0` range does not match IPv4 peers.
- `health` pings the database on every call and is exempt from limiting and shedding; a short cached result would bound it.
- `readBodyWithin` answers `408` but does not cancel the body read.
- `REDIS_URL` and the OTLP endpoint and headers have development defaults that contain credentials; a production start should refuse them.
- `/users` shows only the first page; there are no previous/next links. Needs a product choice.
- A failed log directory stops startup under the default `console,file` transport; confirm that is intended.
- Pages and the API now share one rate-limit allowance; revisit if the pages need a looser budget.
- `tests/d1.ts` (`fakeD1`) accepts booleans and `undefined` bindings that real D1 rejects.
- Performance at scale: every list request counts all rows, offset pagination scans, telemetry samples at 100 % by default, and assets are read from disk per request. Keyset pagination is the real fix for the first two.
- **trigger**: each when its area is next changed.
