## Facts future sessions should know

- The Start plugin owns route-tree generation; build-before-check/typecheck ordering in CI stays because the tree is gitignored.
- `applySecurityHeaders(csp)` always sets the three non-CSP hardening headers and keeps an existing CSP; the docs layer forces `docsCspFor()` because the global middleware runs outside it.
- Page loaders chain `.then(...).catch(...)` — a second `.then` handler does not catch its own first handler's throws, and Start serializes whatever error reaches it onto the error page.
- `pageResponseMeta` (the D7 `x-cache` middleware) is not directly unit-testable (Start's middleware context shape); its coverage is the E2E `x-cache` assertions.
