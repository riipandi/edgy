# Marko features parked — closed

Every entry below was parked while the pages were Marko templates. The pages are Solid now
(plan-20261018_0105), so the Marko mechanisms they describe no longer exist in this tree and each
parking is closed `wontfix`. The need behind an entry may still exist — re-read the Solid docs
(streaming, lazy loading, shared layouts) before opening a new item, and park it against Solid's own
mechanisms.

## 1. Out-of-order streaming (`<try>` with `<@placeholder>`)

- **status**: wontfix (2026-10-18) — the mechanism was Marko's; the pages are Solid. Solid streams
  through `Loading` boundaries in `renderToStream` if a page ever needs it.
- **what**: render a page's shell first and let a slow, secondary part arrive later.
- **why closed**: no page has slow data; the mechanism it was parked against is gone.

## 2. Lazy-loading components (`<component @lazy>`)

- **status**: wontfix (2026-10-18) — the mechanism was Marko's `linkAssets`; Solid's `lazy` and
  `filesystem-routing`'s `codeSplitting` replace it if a page ever needs it.
- **what**: ship an interactive component's script only when it renders.
- **why closed**: one interactive component existed; the routes ship eagerly (`codeSplitting: false`)
  and the payload is negligible.

## 3. Patch-protocol shared layouts

- **status**: wontfix (2026-10-18) — Marko's experimental protocol, gated on `@marko/run` and
  `'unsafe-eval'`; none of it exists here. Solid Router keeps a layout mounted across navigations
  natively.
- **what**: navigation updates the live document with patches, so a layout keeps its state.
- **why closed**: the mechanism was Marko's and experimental; the need is covered by Solid Router.
